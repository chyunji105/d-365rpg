# 수능까지 D-365 RPG

고3의 1년을 직접 걸어다니며 보내고, 내가 고른 선택으로 어울리는 전공을 찾아 주는 진로 게임이에요.

AI(Claude)와 대화하며 아이디어를 다듬고 함께 만들었어요.

## 플레이 방법

1. 이름을 적고 수험생 캐릭터(남학생·여학생)를 골라요.
2. 3월부터 수능 날까지 23개 상황을 지나가요.
   - 학교 곳곳을 걸어다니며 친구, 선생님, 물건 중 하나를 골라요. 상황마다 선택지는 6개예요.
   - 6월·9월 모의평가와 수능 날에는 답안지에 직접 마킹해요(5지선다).
3. 수능이 끝나면 성적표 모양의 결과가 나와요.
   - 12가지 능력치 등급
   - 30개 학과 중 추천 전공과 어울리는 전공
   - 10년 뒤 AI 시대에 그 학과에서 AI가 도와줄 일과 사람만 할 수 있는 일

### 조작
- 컴퓨터: 방향키나 WASD로 걷고, Space나 Enter로 말 걸기·선택, 시험은 숫자 키 1~5로 마킹
- 휴대폰: 지도를 탭하면 걸어가고, 아래 이름 버튼을 누르면 그쪽으로 가서 말을 걸어요

## 결과가 나오는 방식

- 선택지마다 능력치 점수 3점이 쌓여요.
- 능력치 12가지: 논리력, 탐구력, 언어력, 공감력, 창의력, 리더십, 실행력, 정리력, 체력, 국제감각, 예술감각, 꼼꼼함
- 학과마다 중요한 능력치 기준(3·2·1)이 있어요. 내 능력치 비율이 가장 닮은 학과를 추천해요.
- 결과 화면 아래에서 내가 고른 선택, 모든 선택지의 점수, 학과 30개의 기준을 펼쳐 볼 수 있어요.
